# Spring Boot REST API

## 📖 Description
This project was developed for **IT3130 – Application Development Practical 01** using Spring Boot.

## 🚀 Features
- Spring Boot Application
- REST API
- Welcome Endpoint
- Student API
- Greeting API
- Module API

## 📌 API Endpoints

### Welcome
GET /
http://localhost:8080/

### Students
GET /api/students
http://localhost:8080/api/students

### Greeting
GET /api/greeting?name=Sivaganka
http://localhost:8080/api/greeting?name=Sivaganka

### Module
GET /api/module
http://localhost:8080/api/module
